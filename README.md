Task 1 - Data Cleaning & Preprocessing

The retail sales dataset was cleaned and preprocessed using Microsoft Excel, with the following steps:

Handling Missing Values: Identified missing values in the Item, Price Per Unit, Quantity, Total Spent, and Discount Applied columns using Excel's Find & Select feature, and replaced them with NA for consistency.

Duplicate Removal: Checked the dataset for duplicate records using Excel's Remove Duplicates tool to ensure data integrity.

Data Type Correction: Converted the Date, Price Per Unit, and Total Spent columns to their appropriate data types.

Column Header Standardization: Renamed all column headers to lowercase for consistency and ease of reference.

Formatting:
Set text alignment to left-aligned across the dataset.
Adjusted row height and column width using AutoFit for improved readability.
